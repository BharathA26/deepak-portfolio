# Deepak — Portfolio (React + MUI)

This repository contains a single-page portfolio built with React + TypeScript and MUI v5. It includes a responsive Navbar with scroll-spy, Hero with CTAs, Tech & Skills cards, a Gallery with a lightbox, About with resume download, a validated Contact form, and a themed Footer.

Quick start (from `web/`):

- Install: `yarn` or `npm install`
- Run dev: `yarn start`
- Build: `yarn build`

Replace placeholders under `web/public/assets/` with your images and resume. Update contact links in `ContactForm.tsx` and profile content in `About.tsx`.
